``geometor.explorer`` is the interactive visual workbench for the GEOMETOR initiative. It acts as the user interface bridging symbolic geometric modeling in ``geometor.model`` with analytical breakdown in ``geometor.divine``.

With a clean Flask backend and an SVG frontend powered by Vanilla JavaScript and GSAP, ``geometor.explorer`` allows researchers and enthusiasts to construct geometric systems, inspect precise LaTeX/KaTeX algebraic expressions, analyze golden sections in real time, replay construction histories step-by-step, and export high-resolution vector and animated SVG files.
