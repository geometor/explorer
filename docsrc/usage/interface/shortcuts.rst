keyboard shortcuts
==================

Quick reference table of all keyboard shortcuts available in ``geometor.explorer``:

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - Shortcut
     - Action
   * - ``p``
     - Open **Point** creation dialog
   * - ``P``
     - Open **Polynomial** creation dialog
   * - ``l``
     - Activate **Line** construction mode (requires 2 points selected)
   * - ``c``
     - Activate **Circle** construction mode (requires 2 points selected)
   * - ``s``
     - Set **Segment** (requires 2 points selected)
   * - ``S``
     - Set **Section** (requires 3 points selected)
   * - ``y``
     - Set **Polygon** (requires 3+ points selected)
   * - ``f``
     - **Fit** construction in viewport
   * - ``v``
     - Toggle **Zen Mode** (hide all sidebars)
   * - ``~`` / ```` ` ````
     - Toggle **CLI Panel** overlay
   * - **Left Arrow**
     - Step backward on animation timeline
   * - **Right Arrow**
     - Step forward on animation timeline
