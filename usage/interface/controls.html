controls¶

The interface features a left sidebar for construction tools and global options, and a right sidebar for inspecting model history and analytical groupings.

Left Sidebar (Toolbar)¶

The left sidebar is organized into clean functional groups:

  • File Manager: - New: Open template dialog (Blank, Default, Equidistant). - Open: Load saved construction JSON files. - Save / Save As: Save current construction state to ./constructions. - Export SVG: Download static SVG or print-optimized HTML pages. - Export Animated SVG: Download interactive step-by-step animated vector graphics.

  • Construct: - Point (p): Construct a point at specified algebraic coordinates or numeric values. - Polynomial (P): Construct a polynomial curve from comma-separated coefficients. - Line (l): Construct an infinite line passing through two selected points. - Circle (c): Construct a circle centered at point 1 with radius point 2. - Perpendicular Bisector (P B): Construct the perpendicular bisector between two selected points. - Angle Bisector (A B): Construct the angle bisector passing through three selected points (point 1, vertex, point 3).

  • Set: - Segment (s): Define a bounded segment between two points. - Section (S): Define a collinear section of three points. - Polygon (y): Define a polygon bound from three or more ordered points.

  • System Toggles: - Animation Panel: Toggle the playback timeline bar. - Divine Analysis: Live toggle for golden section and harmonic ratio calculation. - Ancestor Highlighting: Toggle visual dependency tree highlighting on hover. - CLI Overlay (~): Open/close the integrated command terminal panel. - Settings: Open global application preferences (Light theme, granular hover toggles).

Right Sidebar (Data Views)¶

The right sidebar provides three views accessible via top tabs:

  • SEQ (Sequential History): The default chronological step-by-step record of all elements. Provides class editing, guide element toggles (orange dotted styling), and deletion controls.

  • CAT (Categorized View): Grouped tables separating Points, Geometric Structures (Lines, Circles, Polynomials), and Graphic Overlays (Segments, Sections, Polygons).

  • GRP (Divine Groupings): Analytical tables generated by geometor.divine, organizing golden sections by Size, Chain, and Point.
