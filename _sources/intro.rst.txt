``geometor.explorer`` is the interactive visual workbench for the GEOMETOR initiative, bridging symbolic geometric modeling in `GEOMETOR • model <https://geometor.github.io/model>`_ with golden-ratio analysis in ``geometor.divine`` and interactive Book Codex documentation in `PHOTON • publish <https://photon-platform.github.io/publish>`_.

With a Flask backend and an SVG frontend powered by Vanilla JavaScript and GSAP, ``geometor.explorer`` enables researchers to construct geometric systems graphically or via the built-in symbolic CLI (`[ A B ]`, `( A B )`, `/ A B /`, `< A B C >`), inspect exact SymPy algebraic expressions via KaTeX hover cards, analyze golden sections in real time, replay construction histories step-by-step, and export interactive SVGs directly compatible with `GEOMETOR • elements <https://geometor.github.io/elements>`_ and `GEOMETOR • etc <https://geometor.github.io/etc>`_.
